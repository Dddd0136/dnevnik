# Рабочий дневник

Оболочка для установки веб-приложения «Рабочий дневник» (Google Apps Script) на телефон.

Здесь только иконки, заставка и экран подключения. Данных и ссылок на таблицу или скрипт здесь нет: адрес скрипта вводится на телефоне и хранится только на нём.

Адрес приложения: https://dddd0136.github.io/dnevnik/
Сменить подключённый адрес: открыть https://dddd0136.github.io/dnevnik/#reset
